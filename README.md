### 🆕 Install:
When on a new machine, just run:
```sh
bash <(curl https://raw.githubusercontent.com/supervanya/.dotfiles/main/init.sh)
```

### 💾 Backup:
When leaving old machine or syncing them.

#### dotfiles
First make sure all dotfiles are backed up and pushed up:
```
config status
```
#### Raycast 
Backup Raycast settings using UI and save the output in the user root as `./raycast.rayconfig` (this could maybe be automated in future)
